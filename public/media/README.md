# MEDIA FOLDERS

Create one folder per stop and drop files in using these exact names:

```
public/media/stop-01/photo-1.jpg
public/media/stop-01/photo-2.jpg
public/media/stop-01/photo-3.jpg
public/media/stop-01/video.mp4
```

`stop-02` … `stop-25` work the same way. The scrapbook picks them up automatically the next
time the page loads — no code changes required.

Missing files show a labelled placeholder inside the game, so it is safe to add them gradually.

Formats: JPG / PNG / WebP / AVIF / GIF, MP4 / WebM video, MP3 / WAV audio.
Keep images around 1600 px wide and videos under ~20 MB for smooth loading.
